## 首先，要连接服务器

```sh
$ mysql -h xxx -u root -p
```

- `xxx`：填上需要连接的 MySQL Server 的 IP

连接成功之后会发现，出现了 `mysql>` 的式样

<!--more-->

## 连接上服务器之后

### 查看服务器上已创建的数据库

```mysql
show databases;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| sys                |
| test               |
+--------------------+
```

> 注意：连接上 MySQL 之后，每一条命令在末尾都要打分号;

### 选择要查询的数据库

```mysql
use test;
Database changed
```

这里是以 `test` 数据库为示例，可以换成其它通过上一步查询到的数据库的名字。

### 查看数据库已创建的表

```mysql
show tables;
+------------------+
| Tables_in_test   |
+------------------+
| students         |
| class            |
+------------------+
```

### 查看想要查询表的结构

```mysql
DESC students;
+----------+--------------+------+-----+---------+----------------+
| Field    | Type         | Null | Key | Default | Extra          |
+----------+--------------+------+-----+---------+----------------+
| id       | bigint       | NO   | PRI | NULL    | auto_increment |
| class_id | bigint       | NO   |     | NULL    |                |
| name     | varchar(100) | NO   |     | NULL    |                |
| gender   | varchar(1)   | NO   |     | NULL    |                |
| score    | int          | NO   |     | NULL    |                |
+----------+--------------+------+-----+---------+----------------+
```

## 最后，使用相应的SQL语句对表进行查询即可

```mysql
Select xxx from xxx where xxx;
```
